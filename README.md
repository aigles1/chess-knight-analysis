# chess-knight-analysis
Learn where the Knight can move in Chess.<br /><br />
I made this using [Grok](https://grok.com) and [Github Copilot](https://github.com/copilot) to help me better visualize the Knight two, three, and four moves ahead.<br /><br />
Left click on the Knight and then right click on the moves you want to visualize next.<br />
Also includes ability to add a random game from top players that have a Knight on the board during the middlegame.
